# MK AI - المساعد الذكي الخارق (ChatGPT Elite Clone & PWA)

تطبيق ذكاء اصطناعي فائق القوة باسم **MK AI** بتصميم ومميزات مطابقة تماماً لـ **ChatGPT**، يعمل بنسبة 100% مباشرة على **GitHub Pages** داخل المتصفح بدون أي سيرفر أو خادم وسيط (Serverless Static PWA)، مع قاعدة بيانات SQLite محلية، ودعم الإملاء الصوتي، والقراءة الصوتية، والتفكير المتعمق (o1 Reasoning).

---

## 🌟 أبرز المميزات والإضافات الجديدة:

### 1. مبدل النماذج المتقدم (Model Switcher):
* **✨ MK 4o (الافتراضي):** فائق السرعة والذكاء للمحادثات اليومية وحل المشكلات وصياغة النصوص.
* **🧠 MK o1 (تفكير عميق):** استدلال منطقي ورياضي عميق مع إظهار خطوات التفكير والتحليل في صندوق قابل للطي (Thought for seconds) قبل كتابة الرد النهائي.
* **💻 MK Coder:** مهندس برمجيات متخصص في كتابة وهندسة الأكواد، وتصحيح الأخطاء، وتقديم أفضل الممارسات البرمجية.

### 2. شريط أدوات الرسائل المتكامل (Message Actions):
* **نسخ الرد (📋):** نسخ كود أو نص الرد بنقرة واحدة مع إشعار تأكيد.
* **الاستماع والقراءة الصوتية (🔊 Read Aloud):** قراءة الرد صوتياً باللغة العربية عبر محرك Web Speech API المدمج في متصفحك.
* **إعادة التوليد (🔄 Regenerate):** إعادة إرسال السؤال لتوليد إجابة جديدة برؤية بديلة.
* **تقييم الردود (👍 / 👎):** زر إبداء الإعجاب أو عدم الرضا.
* **تعديل رسالة المستخدم (✏️ Edit):** تعديل أي سؤال سابق وإعادة إرساله فوراً.

### 3. الإملاء الصوتي المباشر (🎙️ Voice Dictation):
* زر الميكروفون في شريط الإدخال يتيح لك التحدث بصوتك مباشرة باللغة العربية أو الإنجليزية ليتم تحويل كلامك إلى نص فوري دقيق.

### 4. زر إيقاف التوليد الفوري (⏹ Stop Generating):
* أثناء كتابة الذكاء الاصطناعي للرد، يتحول زر الإرسال تلقائياً إلى زر إيقاف فوري بنقرة واحدة (AbortController).

### 5. تنظيم سجل المحادثات حسب التاريخ (Sidebar Date Grouping):
* تنظيم المحادثات تلقائياً في مجموعات: **اليوم**، **أمس**، **الأسبوع الماضي**، و**سابقاً**، مع إمكانية البحث الفوري وإعادة التسمية والتصدير.

### 6. زر الانتقال السريع لأسفل المحادثة (⬇ Scroll to Bottom):
* زر عائم يظهر تلقائياً عند التمرير لأعلى ليعيدك لآخر رسالة بسلاسة.

### 7. قاعدة بيانات SQLite محلية + نسخ احتياطي كامل:
* حفظ مشفر وتلقائي لكل رسالة داخل قاعدة بيانات SQLite عبر WebAssembly في المتصفح.
* **تنزيل نسخة احتياطية كاملة (`.mkbackup`):** لنقل كل محادثاتك وملفاتك إلى هاتف آخر أو استعادتها في أي وقت.

---

## 🚀 كيفية الرفع والتشغيل على GitHub Pages

1. ارفع كافة ملفات المشروع إلى مستودعك على **GitHub**.
2. ادخل إلى: **Settings** > **Pages**.
3. اختر الـ Branch: **main** (أو **master**)، والمجلد: **/ (root)** ثم اضغط **Save**.
4. ستحصل على رابط مباشر يعمل من هاتفك أو حاسوبك، ويمكنك تثبيته كتطبيق مستقل عبر زر **"تثبيت التطبيق على الهاتف"**.
