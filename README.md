# MK AI - المساعد الذكي الخارق (ChatGPT Elite Clone & Supercharged PWA)

تطبيق ذكاء اصطناعي فائق التطور والطلاقة باسم **MK AI** بتصميم ومميزات مطابقة لأحدث إصدارات **ChatGPT**، يعمل بنسبة **100% مباشرة على GitHub Pages** داخل المتصفح بدون أي سيرفر أو خادم وسيط (Serverless Static PWA)، مع قاعدة بيانات **SQLite حقيقية محلياً**، ومزود بالـ 6 ركائز التقنية الخارقة:

---

## 🌟 الركائز الخارقة الستة الجديدة (The 6 Supercharged Pillars):

### 1. قماش المعاينة التفاعلية الحية للأكواد (Interactive Artifacts & Live Canvas Sandbox):
* عند طلب إنشاء أي صفحة ويب، تطبيق، لعبة (مثل Snake أو Pong)، أو أداة حاسوبية، يقوم MK AI ببرمجة التطبيق بالكامل داخل كتلة كود `html` ويفتح تلقائياً **قماش المعاينة الحية (Live Canvas)**.
* **Sandbox Iframe فوري:** تشغيل الكود وتجربة اللعبة أو التطبيق فوراً داخل بيئة معزولة وآمنة.
* **تبديل مقاسات الشاشات التفاعلية:**
  * 🖥️ **سطح المكتب (Desktop):** مقاس كامل.
  * 📱 **الجهاز اللوحي (Tablet):** عرض 768px.
  * 📲 **الهاتف المحمول (Mobile):** عرض 375px بإطار هاتف أنيق.
* **عرض الكود المصدري:** تبديل فوري بين معاينة التطبيق وشفرة الكود الملونة (Syntax Highlighting).
* **تحميل المشروع:** زر بنقرة واحدة لتنزيل ملف الكود المصدري كاملاً (`.html` أو `.svg`).

---

### 2. المحادثة الصوتية الحية المباشرة (Real-Time Live Voice Mode):
* تجربة صوتية حية مطابقة لـ **ChatGPT Advanced Voice Mode**:
* **كرة الصوت المتوهجة الحيوية (Fluid Glowing Voice Orb):** كرة طافية بتدرج لوني ساحر تسترخي وتنبض بالحياة مع تفاعل صوتي حيوي.
* **مرسم الترددات الصوتي الحي (Canvas Waveform Visualizer):** حلقات وترددات موجية دائرية تترجم حالة الصوت بصرياً بدقة فائقة:
  * 🌊 **حالة الاستماع (Listening):** حلقات نيون هادئة تتنفس بنعومة في انتظار صوتك.
  * 🟣 **حالة التفكير (Thinking):** دوامة لولبية أرجوانية دوارة تُظهر الاستدلال المنطقي.
  * 🟢 **حالة التحدث (Speaking):** موجات ترددية زمردية ديناميكية تنبض بتدفق الكلمات.
* **ميزة المقاطعة الصوتية اللحظية (Voice Interruption):** إذا بدأ المستخدم بالحديث أثناء كلام المساعد، يتوقف الذكاء الاصطناعي عن الكلام فوراً ويستمع للمستخدم بدون أي تأخير.
* **شريط الترجمة الحية (Live Subtitles):** عرض نص الحديث المتبادل في الوقت الحقيقي.

---

### 3. استوديو توليد وتصميم الصور الذكي (AI Image Generation Studio - Flux):
* محرك توليد صور فائق الجودة بالاعتماد على نموذج **Flux**:
* التعرف التلقائي على طلبات الرسم والتصميم (مثل *"ارسم صورة لسيارة نيون في المستقبل"* أو عبر زر 🎨 في شريط الإدخال).
* توليد صور مربعة بدقة 1024x1024 بكسل بدون علامات مائية.
* **معرض ملء الشاشة (Fullscreen Lightbox Modal):** تكبير الصورة وفحص تفاصيلها بنقرة واحدة.
* **تنزيل عالي الدقة:** زر تحميل مباشر للصورة بأعلى جودة بصيغة PNG.

---

### 4. متجر وباني المساعدين المتخصصين (Custom MK GPTs Store & Builder):
* نافذة متجر متكاملة ومستوحاة من متجر GPTs الرسمي:
* **مساعدون رسميون مثبتون مسبقاً:**
  * 💻 **MK المهندس البرمجي:** كود نظيف وتطبيقات ويب متكاملة.
  * 📊 **MK المحلل المالي والإحصائي:** دراسات جدوى وأرقام دقيقة.
  * ✍️ **MK الكاتب والمبدع اللغوي:** صياغة إبداعية متدفقة للمقالات والقصص.
  * 🏋️‍♂️ **MK المدرب الرياضي والصحي:** خطط تمارين وتغذية مخصصة.
  * 🌐 **MK الباحث الميداني والتقصي:** حقائق ومعلومات مدققة وروابط موثوقة.
* **باني المساعدين المخصصين (Custom Builder):** واجهة لإنشاء مساعدك الخاص بإيموجي واسم ووصف وتعليمات صارمة (System Prompt) وتخزينها في قاعدة بيانات **SQLite المحلية**.
* التبديل السلس بين المساعدين وبدء محادثات مخصصة بضغطة زر.

---

### 5. محرك البحث المتجهي الدلالي في المستندات (In-Browser Semantic Vector RAG):
* محرك RAG فائق السرعة يعمل محلياً داخل المتصفح:
* عند رفع ملفات PDF أو مستندات نصية أو أكواد برمجية، يقوم المحرك بـ:
  1. استخراج النصوص صفحة بصفحة عبر مكتبة **PDF.js**.
  2. تقسيم المستندات إلى مقاطع نصية دلالية (Chunks) بحدود وتداخل ذكي.
  3. حساب متجهات الأوزان الدلالية (TF-IDF Vector Space).
  4. استخراج أدق الفقرات عبر مقياس تشابه جيب التمام (**Cosine Similarity**).
* تزويد نموذج الذكاء الاصطناعي بأدق الاقتباسات من الكتب والمستندات للإجابة عليها باحترافية وبدون أي هلوسة.

---

### 6. الرسوم البيانية التفاعلية للبيانات (Interactive Data Charts Visualizer):
* تكامل تلقائي فوري مع مكتبة **Chart.js**:
* عند احتواء رد الذكاء الاصطناعي على جدول Markdown يضم بيانات وأرقام إحصائية، يظهر تلقائياً أسفل الجدول زر:
  **"📊 تحويل الجدول إلى رسم بياني تفاعلي"**.
* نافذة عرض الرسم البياني تدعم التبديل اللحظي بين 4 أنواع من المخططات:
  * 📊 **أعمدة (Bar Chart)**.
  * 📈 **خطّي (Line Chart)**.
  * 🥧 **دائري (Pie Chart)**.
  * 🍩 **حلقي (Doughnut Chart)**.
* زر **تنزيل الرسم كصورة PNG** لحفظه ومشاركته في التقارير.

## 💎 المميزات الأساسية الأخرى:

1. **حوار طبيعي وبحث تلقائي في الويب:** حوار إنساني ذكي ومرن في أي مجال، مع استحضار أحدث البيانات من الويب بهدوء بدون عبارات آلية متكلفة ("بحثت في الإنترنت").
2. **استدلال وتفكير عميق (MK o1):** صندوق منسدل لعرض خطوات التفكير والتحليل المنطقي قبل الإجابة.
3. **بحث فوري داخل رسائل المحادثة (In-Chat Search):** تحديد الكلمات والانتقال المباشر للرسائل المطابقة.
4. **تثبيت المحادثات (Pinned Chats):** تثبيت المحادثات الهامة وتنظيم باقي المحادثات زمنياً (اليوم، أمس، الأسبوع الماضي، سابقاً).
5. **تصدير المحادثات متعدد الصيغ:** طباعة أو حفظ كـ PDF، تصدير Markdown (.md)، وتصدير JSON.
6. **مؤثرات صوتية تفاعلية (Audio Cues):** نغمات خفيفة وأنيقة عبر Web Audio API عند الإرسال وانتهاء الرد.
7. **إملاء صوتي وقراءة مسموعة:** إملاء مباشر لشريط الكتابة، وقراءة مسموعة واضحة لأي رد.
8. **قاعدة بيانات SQLite محلية (WASM):** حفظ كامل مشفر وسريع في متصفحك عبر `sql.js` و `IndexedDB`.
9. **نسخ احتياطي شامل (.mkbackup):** تنزيل كامل قاعدة البيانات بملفاتها ومساعديها واستعادتها ونقلها من هاتف لآخر بنقرة واحدة.
10. **تطبيق ويب تقدمي (PWA):** إمكانية تثبيت التطبيق على الشاشة الرئيسية للهواتف وأجهزة الكمبيوتر ليعمل كتطبيق أصلي (Native App).

## 🚀 كيفية الرفع والتشغيل على GitHub Pages

1. ارفع كافة الملفات الموجودة في المجلد إلى مستودعك على **GitHub**:
   ```bash
   git add .
   git commit -m "Launch MK AI Ultra Supercharged"
   git push origin main
   ```
2. ادخل إلى إعدادات المستودع: **Settings** > **Pages**.
3. في خيار **Source**، اختر **Deploy from a branch**.
4. اختر الـ Branch: **main** (أو **master**)، والمجلد: **/ (root)** ثم اضغط **Save**.
5. ستحصل على رابط مباشر يعمل بنسبة 100% من هاتفك أو حاسوبك، ويمكنك تثبيته كتطبيق مستقل عبر زر **"تثبيت التطبيق على الهاتف"**.
